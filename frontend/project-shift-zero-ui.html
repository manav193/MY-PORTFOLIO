SHIFT-ZERO UI

A high-contrast HUD and premium menu language designed for split-second readability inside a modifier-driven action game.

01. Problem

Clarity inside visual intensity.

Fast action games can lose critical state information inside particles, motion and aggressive art direction. The interface needs to communicate modifiers, score, objectives and danger without breaking immersion or covering the playfield.

02. Direction

Technical, angular, readable.

  • High-contrast status hierarchy
  • Premium dashboard-style menu
  • Command-oriented navigation
  • Live system-score visual direction
  • Execution-pipeline and metric cards
  • Reserved accent colors for critical state
  • Responsive static reconstruction
  • Reduced visual noise around core information
03. Relationship

Design system for the Godot project.

This repository isolates the visual language from the wider SHIFT-ZERO game architecture. It allows menus, HUD hierarchy and interaction states to be explored independently before they are integrated into production Godot scenes.

04. Decision

Accents communicate state.

Saturated color is reserved for warnings, active modifiers and important actions. Neutral surfaces carry structure so that gameplay-critical changes remain immediately noticeable.

05. Outcome

A reusable presentation direction.

The concept provides a coherent menu and HUD target for the main game while demonstrating game-interface design, responsive implementation and information hierarchy as a standalone portfolio project.
